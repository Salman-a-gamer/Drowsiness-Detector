# Midnight Signal

`midnight-signal.wav` is an original 15-second synthesized horror soundscape made by
`src/drowsy_guard/soundscape.py`: drone, heartbeat, synthetic screech, static, and
detuned tones. No samples, FNAF music, or third-party recordings are used.

The project dedicates this audio asset to the public domain under CC0 1.0:
https://creativecommons.org/publicdomain/zero/1.0/

It is copied into the user's writable music folder on first launch. A selected
custom BGM replaces it; the app never layers both tracks.
